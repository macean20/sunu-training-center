# SUNU TRAINING CENTER

Plateforme web de recrutement et d'intérim spécialisée en **Gestion de la Relation Client (GRC)** à Dakar, Sénégal.

> Projet réalisé dans le cadre du **Hackathon GP26** — Digital Campus Dakar / ISM.

## 🎯 Démo en ligne

**[https://sunu-training-center.pages.dev](https://sunu-training-center.pages.dev)** _(à mettre à jour après déploiement)_

## ✨ Fonctionnalités

### Espace Étudiant / Candidat
- 📋 Création de compte avec validation administrateur
- 💼 Consultation des offres d'emploi filtrables par secteur
- 📤 Dépôt de CV et candidature
- 🧪 Tests techniques (orthographe, élocution, bureautique Office)
- 📨 Messagerie bidirectionnelle avec accusés de réception
- 👤 Profil personnel et calendrier d'entretiens

### Espace Administrateur
- 📊 Dashboard KPIs avec graphiques (Chart.js)
- ⏳ Gestion des demandes de comptes en attente
- 👥 Gestion du vivier candidats (lecture seule)
- 📨 Messagerie : lecture, réponse, validation/refus de demandes
- 💼 Gestion des offres d'emploi
- 🤝 Gestion des partenaires entreprises
- 📈 Vue partenaire intégrée (anciennement espace séparé)
- 🧪 Résultats détaillés des tests par candidat
- 🔒 Module RGPD et sauvegarde

## 🛠 Stack technique

- HTML5, CSS3, JavaScript vanilla (aucun framework)
- Chart.js 4.4 pour les graphiques
- Font Awesome 6.5 pour les icônes
- Google Fonts (DM Sans + Lucida Console)
- Persistance via `localStorage` (aucun backend requis)

## 📁 Structure

Le projet est volontairement contenu dans **un seul fichier `index.html`** pour faciliter le déploiement sur des hébergeurs statiques. Tout le CSS et le JavaScript sont intégrés.
